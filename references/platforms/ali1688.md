# 1688 Platform Guide

> Endpoint: `https://mcp.sorftime.com/1688` · 6 tools · 仅中国大陆，无 site 参数
> 定位：工厂直连货源端，与 Amazon 端点联用完成「选品→找货→利润测算」闭环

## Parameter Traps（调错第一原因，先看这张表）

| 概念 | 实际参数（2026-10-10 活 schema） |
|------|------|
| 搜索词 | `ali1688_similar_product` 用 **`search_name`**（Amazon 端点同类概念大多叫 `keyword`，跨端点时别套错名） |
| 产品 ID | 6 个业务工具统一用 **`product_id`**（`ali1688_product_request` / `ali1688_product_variations` 必填） |
| 类目 | `node_id`，仅 `ali1688_category_tree` 和 `ali1688_product_search` 支持，其他工具无类目参数 |
| 图搜 | `image_url`，必须是**真实可访问的图片 URL**，占位符/无效链接不会命中 |
| 商家资质 | `supplier_type` 传码值：`1`=实力商家、`2`=超级工厂 |
| 权益码 | `rights` 传字符串形如 `"1,2,3"`（逗号分隔码值，非数组） |

## Tool Reference

| 工具 | 必填 | 说明 |
|------|------|------|
| `ali1688_category_tree` | —（可选 `node_id` 下探） | 全量类目树，找货源类目的入口 |
| `ali1688_similar_product` | `search_name` | 关键词找货，返回约 100 条：title/photo/url/price/product_id/store_name/service_score/sales_of_30d。**实测有真数据**（`{"search_name":"yoga mat"}` ✅），拿到标题/关键词后的第一跳 |
| `ali1688_product_search` | —（全可选） | 20+ 筛选维度精准找货：`node_id`/`supplier_type`/`supplier_member_type`/`rights`/`dropshipping_price_range_min·max`/`cumulative_sale_count_min·max`/`recent_30_day_sale_min·max`/`repurchase_rate_min·max`/`service_score_min·max`/`sku_count_min·max`/`stock_count_min·max`/`online_date_range_min·max`/`page`。**裸奔（全不传）= 浏览模式**；组合过滤 = 精准货源筛选。配 `supplier_type=2` 锁定超级工厂 |
| `ali1688_product_request` | `product_id` | 产品详情 16 字段：价格/MOQ/供应商信息，定货源后必取 |
| `ali1688_product_variations` | `product_id` | SKU 级明细：每变体的价格/库存/重量/尺寸，用于采购成本与物流重量核算 |
| `ali1688_product_search_from_image` | `image_url` | 反向图搜，发现同款货源。需真实图片 URL |

## 联动工作流：亚马逊选品 → 1688 找货（本页独有价值）

双端点链路，**两页同读**（`references/platforms/amazon.md` + 本页）：

1. **Amazon 端点定候选**：`product_search` 或 `potential_product`（隐赚指数）筛出候选产品，取标题/关键词
2. **1688 找同款货源**：拿标题调 `ali1688_similar_product`（快速看约 100 条），或用关键词调 `ali1688_product_search`——加 `supplier_type=2` 过滤超级工厂
3. **取详情**：`ali1688_product_request` 拿 16 字段（价格/MOQ/供应商信息）
4. **取 SKU 明细**：`ali1688_product_variations` 拿每变体价格/库存/重量/尺寸
5. **算利润**：成本数据喂给 `references/scripts-guide.md` 中的 calculator.py 利润测算，结合 Amazon 端点 `product_detail` 的售价/佣金完成采购决策

## Gotchas

- 1688 无 site 参数（仅中国大陆），6 个业务工具 + 通用配额工具 `common_usage_query`；工具名/参数名与活 schema 逐一核对
- `ali1688_product_search` 全参数可选——首调可裸奔浏览看返回形态，再逐步叠加过滤
- 反向图搜 `ali1688_product_search_from_image` 对图片 URL 质量敏感，无效 URL 返回空
- MCP SDK 锁 1.x、响应 `{doc,data}` 包裹、中文叙事前缀等通用坑 → `references/gotchas.md`
- 利润测算脚本（calculator.py）用法 → `references/scripts-guide.md`
